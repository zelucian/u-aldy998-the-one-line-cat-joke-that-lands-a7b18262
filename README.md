A one-line cat joke entry for make.fun, built around the moment a cat's stare at nothing convinces the whole house the nothing is real.

> My cat stared at the wall for an hour, so we sold the house.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Running it writes the entry line to out/entry.txt, byte-identical on every run.
